# Snapbuild — тестовое задание

Стартовый Nuxt-шаблон для развития продуктового лендинга [Снэпбилд](https://snapbuild.ru/). Проект настроен для статической генерации, автоматических проверок и публикации на GitHub Pages.

## Опубликованная версия

После первого успешного workflow: https://igor-popryadukhin.github.io/snapbuild-test-task/

## Локальный запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run lint
npm run typecheck
npm run test
npm run generate
npm run preview
```

## Стек

- Nuxt 4 и Vue 3 Composition API
- TypeScript
- CSS design tokens и адаптивная сетка без внешнего UI-kit
- Vitest и Nuxt Test Utils
- ESLint
- GitHub Actions и GitHub Pages

## План пяти новых секций

1. Сценарии использования — интерактивные сценарии для маркетинга, дизайна и продаж.
2. Процесс внедрения — этапы подключения дизайн-системы.
3. Измеримый эффект — продуктовые метрики и сравнение процесса до/после.
4. Истории клиентов — отзывы с конкретными результатами.
5. Запросить демо — форма с валидацией, ошибками и успешным состоянием.

## Анализ стилистики

Зафиксированы основные паттерны исходного сайта: крупная акцидентная типографика, монохромная база, яркие акценты, большие скруглённые поверхности, плотная модульная сетка, спокойные микроанимации и контрастное чередование светлых и тёмных секций. Они вынесены в CSS-переменные и базовые компоненты, чтобы новые блоки не выглядели чужеродно.

## Воспроизведённые части

На этапе шаблона подготовлены адаптивные шапка, hero-секция, каркас содержательных блоков и подвал. Полное воспроизведение продуктовых секций будет выполняться следующим этапом.

## Ограничения текущего этапа

Это архитектурный шаблон: контент, графика и интерактивность пяти секций пока представлены каркасом. Такой порядок позволяет сначала зафиксировать структуру, качество сборки и публикацию, а затем спокойно довести визуальную точность.
